# Security

oulabi.dev is a static site: a Next.js static export served as files. It has no backend, no accounts and no forms,
and it stores no visitor data on a server. What it remembers (the motion and sound choices, the volume, your star in
the sky) stays in your own browser's local storage. Page views and performance are measured with Vercel Web Analytics
and Speed Insights.

## Reporting a vulnerability

Please report it privately, not in a public issue:

- through GitHub's private vulnerability reporting on this repository (the Security tab, "Report a vulnerability"), or
- by email to [it.moh.ou@gmail.com](mailto:it.moh.ou@gmail.com).

Say what you found, where, and how to reproduce it. There is no bug bounty.
